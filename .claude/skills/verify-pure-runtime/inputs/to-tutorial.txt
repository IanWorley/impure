# to-*.txt script, are timed for a save that already exists: then the Escape at frame 3,420 opens
# the tutorial's pause menu, which the next Return resumes. With no save, the `No Save File
# Found` and `Save Successful` dialogs take two of the Returns and the Escape lands on the

# still runs, and one run of it creates the save the other scripts need.
# The tutorial then shows instructions that A dismisses and one that waits for a fresh pull of
# the throttle; when each appears depends on the frame rate. So from frame 3,610 the script
# holds the throttle (W), and every 150 frames eases off it, taps Return, and pulls it again. A
# frame capture before each menu press and every 300 frames while riding.
